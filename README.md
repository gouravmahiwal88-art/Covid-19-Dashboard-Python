# COVID-19 Data Analytics & Forecasting Dashboard

An ultra-modern, fully interactive COVID-19 Data Analytics platform built using Python. The application implements an in-memory data cleaning pipeline, detailed exploratory data analysis (EDA), interactive Plotly and Folium geospatial mapping, a Scikit-Learn Polynomial Linear Regression forecasting model, and an voice-enabled AI conversational assistant directly in the web browser.

---

## 🌟 Key Features

1. **Dual-Mode Data Engine**:
   - **Offline Mode (Simulated Messy Data)**: Loads and parses local raw datasets containing duplicates, null records, and inconsistent date formats. This serves to demonstrate the automated processing capability of the data cleaning pipeline.
   - **Live Online Mode**: Connects directly to the **disease.sh Global API** to fetch and format real-time cases, deaths, recoveries, and immunization rollouts globally.

2. **Automated Data Cleaning Pipeline**:
   - Parses mixed and messy date formats (`YYYY-MM-DD`, `DD/MM/YYYY`, `MM-DD-YYYY`) into standard ISO format.
   - Automatically identifies and purges duplicate records.
   - Rectifies missing fields (`NaN`) using country-grouped Forward-Filling (`ffill`) and Backward-Filling (`bfill`) algorithms.

3. **Premium Glassmorphic Dark-Themed UI**:
   - Streamlit interface overridden with custom CSS elements, including Outfit Google Typography, frosted translucent dashboard containers, glowing borders, hover elevations, and responsive grids.

4. **Advanced Machine Learning Predictions**:
   - Incorporates a **Scikit-Learn Polynomial Regression model** to forecast infection spreads and cumulative mortality rates.
   - Provides confidence boundaries (95% prediction intervals) plotted dynamically to show forecasting uncertainty over custom horizons (7 to 90 days).
   - Showcases metrics: $R^2$ (coefficient of determination) and Root Mean Squared Error (RMSE) dynamically updated upon parameters adjustments.

5. **Folium Geospatial Mapping**:
   - Integrates custom leaf map layers with bubble overlay vectors representing infected magnitudes (on a logarithmic radius scale) and custom HTML popups indicating cases, recoveries, and vaccination coverage.

6. **Interactive Voice & Text Chatbot Assistant**:
   - Built-in conversational AI capable of answering statistical and forecasting questions (e.g., *"What is the death rate in Brazil?"* or *"Predict cases in India next 30 days"*).
   - Employs native HTML5 Web Speech APIs (`webkitSpeechRecognition` and `SpeechSynthesis`) to support direct speech-to-text mic recording and real-time speech responses natively in the browser without installing external binary packages.

## ⚙️ Setup & Execution Guide

Follow these quick steps to get the environment running on your machine:

### 1. Pre-requisites
Ensure you have **Python 3.9** or higher installed on your macOS or preferred OS.

### 2. Install Project Dependencies
Navigate to the project directory and install the required libraries:
```bash
cd covid19_project
python -m pip install -r requirements.txt
```

### 3. Generate Messy Sample Data
If you want to use the offline before/after cleaning showcase, populate the raw CSV files by executing the generator script:
```bash
python3 data/generate_sample_data.py
```
This generates the raw, messy datasets under the `data/` folder.

### 4. Populate Static Visualizations
To pre-render the static analytical charts inside the `visuals/` directory, run the runner script:
```bash
python3 notebooks/run_analysis.py
```

### 5. Launch the Streamlit Dashboard
Start the local server and open the web dashboard:
```bash
python -m streamlit run app.py
```
Streamlit will automatically open a tab in your default browser at `http://localhost:8501`.

### 6. Run the Step-by-Step Jupyter Notebook
To inspect the documented data science pipeline cell-by-cell:
```bash
jupyter notebook notebooks/eda_and_ml.ipynb
```

## 🔮 ML Modeling Explanation

The machine learning forecaster transforms time-series dates into an index of **Days Elapsed** since data recording began. 
A purely linear regression line can fail to capture epidemiological curves (multi-wave spikes, flattening shapes). To solve this:
- **Polynomial Features** transform the input matrix into higher-degree terms ($x \rightarrow [x, x^2, x^3]$).
- A **Scikit-Learn Linear Regression model** is fitted on this transformed matrix.
- Residual variance $\sigma$ is computed on training points.
- Future predictions are computed using:
  $$\hat{y} = \beta_0 + \beta_1 x + \beta_2 x^2 + \dots$$
- An expanding **Uncertainty Envelope** is calculated dynamically at 95% confidence using:
  $$\text{Interval}_t = \pm 1.96 \cdot \sigma \cdot k_t$$
  Where $k_t$ scales linearly over the forecast horizon to model growing projection uncertainty.
